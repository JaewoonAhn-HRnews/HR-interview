# AI 면접 도우미 (인성·직무 면접)

면접관이 화면의 질문을 읽어 주면, 면접자의 답변을 **실시간 음성 받아쓰기**로 기록하고, AI(Claude)가 그 답변을 분석해 **즉석 꼬리질문**을 제안합니다. 면접이 끝나면 전체 기록을 분석해 **어떤 사람인지 정리하고 회사 인성검사 결과와 척도별로 비교**한 보고서를 만듭니다.

## 주요 기능

| 단계 | 기능 |
|---|---|
| 1. 면접 준비 | 지원자 정보·지원 직무·채용공고 입력, 인성검사 척도별 점수 입력(척도 추가/삭제 가능), 검사 보고서 메모 |
| 2. 면접 진행 | 인성/직무 질문 은행, ✨ 지원 직무 맞춤 질문 생성, 직접 질문 입력 · 🎤 한국어 음성 받아쓰기(수정 가능) · 답변 요약, 구체성, 빠진 부분, 관찰된 특성 · 추천 꼬리질문 2~3개 → "이 질문 하기"로 바로 이어가기 |
| 3. 분석 결과 | 한 줄 요약, 성향·업무 스타일 · **인성검사 점수 vs 면접 추정 비교표**(일치/부분일치/불일치/판단불가 + 근거 인용) · 직무 역량 평가 · 강점/우려/모순 지점 · 다음 면접 확인 질문 · 인쇄/PDF, JSON 다운로드 |

면접 기록은 브라우저에 자동 저장되고, **저장** 버튼으로 서버의 `data/sessions/` 에도 저장됩니다(분석 시 자동 저장).

## 실행 방법

필요: Node.js 22.9 이상, Anthropic API 키

```bash
npm install
cp .env.example .env      # .env 파일을 열어 ANTHROPIC_API_KEY 입력
npm start                 # http://localhost:3000 접속
```

- **음성 받아쓰기는 Chrome 또는 Edge**에서 동작합니다(브라우저 내장 Web Speech API, `ko-KR`). 처음 녹음할 때 마이크 권한을 허용하세요. 다른 브라우저에서는 답변을 직접 입력하면 됩니다.
- 마이크 사용은 `localhost` 또는 HTTPS 주소에서만 허용됩니다. 다른 PC에서 접속하게 하려면 HTTPS 를 설정하세요.

## 회사 인성검사에 맞추기

`data/personality-scales.json` 의 척도를 실제 검사 척도로 바꿔 주세요. 현재 들어 있는 8개 척도(성실성, 책임감, 협조성 …)는 **예시**입니다.

```json
{
  "testName": "우리회사 인성검사",
  "scales": [
    { "id": "stress", "name": "스트레스 내성", "description": "압박 상황에서 수행을 유지하는 정도",
      "min": 1, "max": 10, "high": "침착, 회복 빠름", "low": "쉽게 위축" }
  ]
}
```

- `id`: 영문 고유값, `min`/`max`: 점수 범위(T점수라면 20~80 등), `high`/`low`: 점수가 높을/낮을 때 의미 → AI가 비교할 때 사용합니다.
- 기본 질문은 `data/questions.json` 에서 수정합니다.

## 구조

```
server.js                    Express 서버 (API + 정적 파일)
lib/ai.js                    Claude API 호출 - 꼬리질문 / 직무질문 / 종합분석 (JSON 스키마 구조화 출력)
public/                      화면 (index.html, app.js, style.css)
data/questions.json          질문 은행
data/personality-scales.json 인성검사 척도 설정
data/sessions/               저장된 면접 기록 (git 제외)
```

- 모델: `claude-opus-5-5` (`.env` 의 `ANTHROPIC_MODEL` 로 변경 가능). 꼬리질문은 빠른 응답을 위해 낮은 effort, 종합 분석은 높은 effort 로 호출합니다.
- AI가 요청을 거절하는 드문 경우를 대비해 서버 측 대체 모델(fallback) 옵션을 켜 두었습니다.

## 유의 사항

- 면접 답변은 분석을 위해 Anthropic API 로 전송됩니다. **지원자에게 녹음·AI 분석에 대한 개인정보 수집·이용 동의**를 받아 주세요.
- AI에는 성별·나이·출신·외모 등 직무와 무관한 요소를 판단에 쓰지 말고, 근거가 없으면 "판단불가"로 답하도록 지시되어 있습니다.
- 분석 결과와 추천 의견은 **참고 자료**이며, 채용 결정은 면접관이 내려야 합니다.
